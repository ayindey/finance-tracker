New user default password

New accounts you create will be given this password. Tell the new user to change it after their first login.

KOT printer (in the store)

Prints automatically the moment an order is placed, and again any time items are added or removed before the bill is settled — so whoever is packing always has the current list.

Bill printer (at the cashier)

Prints automatically the moment an invoice is marked paid.

If one printer is out of order, or you only have one printer, you can enter the same IP address in both sections above — both tickets will print to it.

Local print agent

If this app is hosted in the cloud (Railway, Render, etc.), it can't reach your printer's IP directly — your printer sits on your shop's private network, and the cloud server has no path into it. The local print agent is a small script you run on any computer inside your shop; it checks in with this app over the internet and forwards print jobs to your printer over your local network, where it can actually reach it.
